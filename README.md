# Property Auctioneers

A group project building a website for a property auctioneers, simulating a mid-size business with realistic needs and goals. The project helped us learn how to work as a team and gave us a grounding in website development fundamentals.

## Overview

The site manages a database containing clients and three types of property:

- **Residential property**
- **Office property**
- **Land property**

## Features

- **Add and delete pages** for clients and each type of property.
- **Amend/view pages** that display the details of a client or property, with a button to edit those details.
- **Reports** for each area, listing the key details in a clean, sortable view for analysing the data.
- **Bid report** covering bids placed on properties.
