Make a Bid

This section allows you to create and manage bids on available properties. Use the menu on the left to either place a new bid or withdraw an existing bid.

Selecting Make a Bid will open the form where you can submit a bid for a property. Selecting Withdraw a Bid will allow you to cancel an existing bid if necessary.
